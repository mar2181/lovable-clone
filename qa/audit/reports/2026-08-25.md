The worker is reachable (`/health → 200`, `/api/spec.json → 200`, `/api/projects anon → 401` correct), but the core product function (build SSE pipeline) cannot be confirmed green or red without a valid Clerk JWT or a dedicated audit API key.

**Fix (methodology — needs a code/config change):**
Add a dedicated `AUDIT_API_KEY` secret to the worker (`wrangler secret put AUDIT_API_KEY`) with its own auth path in `auth.ts` that grants owner-level access for build testing only. This key would be stored in the cloud run environment and used by the audit probe. Without this, the audit's most important check is blind every run.

Until then: **run `node qa/audit/audit-probe.mjs --deep` locally** after each deploy to confirm build engine health.
